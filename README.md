# Jaron Wilson's Portfolio

This is the source code for my personal portfolio website.

## Adding a new project

To add a new project to the portfolio, follow these steps:

1.  Create a new directory for your project (e.g., `my-new-project/`).
2.  Add an `index.html` file to your new directory.
3.  Add a new entry to the `projects.json` file. The entry should have the following format:

    ```json
    {
      "title": "My New Project",
      "description": "A brief description of my new project.",
      "link": "/my-new-project/"
    }
    ```
